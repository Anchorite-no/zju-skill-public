# 本科选课工作流

一个学期的选课分几轮、几种方式进行，按下面的顺序推进。命令参数、结果状态和选课规则见 [选课](../references/zdbk-selection.md)；每一步写操作仍需当前任务授权，歧义时先让用户明确目标。

## 1. 开始前

- `notice list --keyword 选课` 读当期选课通知，确认本人年级所处轮次和时间窗；时间、阈值和志愿数以通知为准。
- `zdbk plan view` 取本人培养方案（PDF 路径在 file，用 `doc text` 读），确认课程代码和预置课。

## 2. 常规选课（前三轮）

1. 阅读适用本人年级、学期的通知，对照培养方案检查课程代码和预置课。新生与老生前两轮的日期不同。
2. 在“自主选课”通过本类（专业）、跨类（专业）、分类页签或搜索引擎找课，再展开教学班。
3. 核对教师、学分、学期、上课与考试时间、地点、面向对象、预修要求、语言、容量和待定人数。
4. 开放期提交志愿，需要调整时在“选课信息”中排序或退选。提交后等待统一筛选。
5. 结果公布后重新读取已选和课表，确认缺课情况，再决定下一轮、低定或补选。

对应命令：`zdbk selection sections --course 课程名` 找教学班 → `select --course 课程名 --teacher 教师 --confirm` 保存志愿 → 需要调整时 `reorder` 或 `drop` → `selected` 回查。志愿保存后要等学校统一筛选，不是先到先得。

## 3. 低学分定点选课

- 先用 `zdbk selection credits` 看当前学分；已选上、待定和补选申请课程合计 ≤22 分才参加，口径见 [低定资格与余量](../references/zdbk-selection.md#低定资格与余量)。
- 通过 `zdbk selection sections --course 课程名` 查询当前教学班，由用户选择后使用普通单次 `select`；不设置等待、轮询或自动抢课。
- 通知建议先低定，再提交补选申请。

## 4. 补选申请

CLI 尚未接入补退选申请，由用户在教务网网页办理：

1. 进入“选课管理 → 补退选申请”，搜索课程与教学班。官方建议申请有余量或补选申请人数少的班。
2. 系统检查条件，普通补选前端打开申请表，并要求申请理由和联系电话；冲突、免听等字段应由实际表单与校验结果取得。
3. 提交后等待开课院系教学管理部门审核。页面明确提示“审核通过，系统会自动选进课表”。
4. 查询“已申请补退选教学班列表”的审核结果，再核实课表中实际班级、教师、时间与地点。

## 5. 退课

- 常规和低定开放期内，直接退选用 `zdbk selection drop --course 课程名 --teacher 教师 --confirm`。
- 之后的退课申请走补退选模块，需要审批，在网页办理。
